# 🏫 INFT-41000-Assignment-3
## ▶️ How to Run
### 🐳 Using Docker
#### 🪜 Steps

##### Step 1. Pull Docker Image
```Dockerfile
docker pull lamoguy/inft-41000-assignment-2
```

##### Step 2. Run Docker Container
```Dockerfile
docker run -p 8501:8501 inft-41000-streamlit-app
```

##### Step 3. Access App from Browser
Go to any browser of choice and go to <http://localhost:8501> 

### 💻 From Source
**Prequisites** 
- Python version >= 3.11

#### 🪜 Steps
##### Step 1. Clone repo
```git
git clone https://github.com/Ozair-Rahman/INFT-41000-Assignment-2
```

##### Step 2. cd into repo
```bash
cd INFT-41000-Assignment-2 
```

##### Step 3. Install Dependencies
```python
pip install -r requirements
```

##### Step 4. Run Application
```python
streamlit run app.py
```

##### Step 5. Access Application From URL
Go to any browser of choice and go to :
<http://localhost:8501>
